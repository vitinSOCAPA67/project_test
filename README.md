Instruções de Execução:

Ao iniciar o programa, o usuário visualiza um menu com diversas opções. É possível cadastrar funcionários, realizar login, consultar os recursos da empresa e visualizar o estado das portas de acesso.

As portas são representadas por uma matriz 3x3, onde cada posição pode estar como 'Livre' ou 'Ocupado'. O sistema permite alterar esses estados para simular o controle de acesso aos ambientes da empresa.

Além disso, os dados dos funcionários são armazenados em dicionários, permitindo a autenticação por usuário e senha.

O projeto também utiliza um arquivo CSV para armazenar custos relacionados aos acessos. Esses dados podem ser lidos, processados e somados, gerando um painel consolidado com informações da empresa, da matriz de acesso e do custo total.

O objetivo do sistema é demonstrar conceitos de segurança, controle de acesso, manipulação de arquivos CSV, matrizes, listas, dicionários e validação de dados em Python."
